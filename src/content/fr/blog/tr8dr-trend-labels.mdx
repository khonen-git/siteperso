## Pourquoi j'ai lancé cette piste

Tout le lab aval (process gates, HMM, events) repose sur un **y** de segments directionnels gelé. Si le label est bruit de coding ou non séparable économiquement, le reste est décoratif.

Pipeline : census L0 → validité <MathInline>{"D(h)"}</MathInline> → screening univarié T2/T5 → stack C4 → lock OOS 2024.

## Définition (résumé)

Segments up / neutral / down via amplitude min + timeout d'inactivité :

<MathBlock>{"D(h) = P(r_{t\\to t+h}>0 \\mid y=\\mathrm{up}) - P(r_{t\\to t+h}>0 \\mid y=\\mathrm{down})"}</MathBlock>
