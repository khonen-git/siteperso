<NotaBene>

**En bref.** Quand la tendance courte (DC 5p) diverge de la longue (DC 15p), le marché entre dans un état de « pullback » mesurable. Sur 2023, **~79 %** des épisodes se résolvent par _Resume_ (R), stable disc/dev. Le score causal prédit R vs F **OOS** (ΔLL jusqu'à **+137**). En revanche, la tradabilité nette **échoue** : EV **−0,22 pip** en dev sous spread 0,2.

</NotaBene>

## Pourquoi j'ai lancé cette piste

C'est le motif le plus visuel en price action : une tendance de fond avec un retracement plus court qui « tire dans l'autre sens ». Avant de trader quoi que ce soit, je voulais savoir si c'était un **processus** (états R/F avec competing risks) ou du bruit étiqueté après coup.

Le framework **gates 0→4** impose cette discipline : existence → détection → prédictibilité → tradabilité, sans optimiser les gates amont sur le PnL.

## Définition (résumé)

Un épisode démarre quand <MathInline>{"\\mathrm{sign}(T_L) \\neq \\mathrm{sign}(T_S)"}</MathInline> (tendance longue DC 15p vs courte DC 5p), avec conflit minimal 3 bars. Issues :

| Issue   | Symbole | Sens                        |
| ------- | ------- | --------------------------- |
| Resume  | R       | La courte rejoint la longue |
| Fail    | F       | La structure longue casse   |
| Censure | C       | Fin de série / split        |

<MathBlock>{'p(R \\mid R \\cup F) \\approx 0{,}79 \\quad \\text{(stable disc/dev)}'}</MathBlock>

**R et F sont des états de structure, pas des PnL.**

## Ce que j'en retiens

| Question                      | Réponse                                 |
| ----------------------------- | --------------------------------------- |
| Le pullback existe-t-il ?     | **Oui** — > null, taux R stable         |
| Peut-on prédire l'issue OOS ? | **Oui** — ΔLL significatif              |
| Faut-il le trader tel quel ?  | **Non** — asymétrie MFE/MAE défavorable |

> Un bon score de **prédictibilité d'état** n'implique pas un edge **exécutable**.

**Usage recommandé :** feature / filtre de régime dans un stack aval (HMM, permission Tr8dr), pas signal standalone.
