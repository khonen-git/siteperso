# Tests Statistiques

## Introduction

<MdxCard>
  Les tests statistiques sont des outils fondamentaux en statistique inférentielle permettant de
  prendre des décisions à partir de données échantillonnées. Ils nous aident à déterminer si les
  différences ou relations observées dans nos données sont statistiquement significatives ou
  simplement dues au hasard.
</MdxCard>

## Principes Fondamentaux

<MdxCard>
**1. Formulation des hypothèses** — H₀ : hypothèse nulle (ce que l'on cherche à rejeter) ; H₁ : hypothèse alternative (ce que l'on cherche à démontrer).

**2. Choix du test approprié** — selon la nature des données, les conditions d'application et l'objectif de l'étude.

**3. Définition du seuil de signification (α)** — généralement 5 % (0,05) ou 1 % (0,01) ; représente le risque d'erreur de type I.

**4. Calcul de la statistique de test** — transformation des données en une valeur unique, comparée à la distribution théorique.

**5. Prise de décision** — basée sur la p-valeur ou la valeur critique, avec interprétation dans le contexte.
</MdxCard>

## Choix du Test Statistique

<MdxCard>
**Nature des variables** : qualitatives (nominales, ordinales) ou quantitatives (discrètes, continues).

**Distribution des données** : normalité, homoscédasticité, indépendance.

**Taille de l'échantillon** : petits échantillons (n &lt; 30) vs grands (n ≥ 30).

**Objectif de l'analyse** : comparaison de moyennes, analyse de relations, test d'adéquation.
</MdxCard>

## Puissance Statistique

<MdxCard>
La puissance d'un test statistique est sa capacité à détecter un effet lorsqu'il existe réellement. Elle est influencée par la **taille de l'échantillon (n)** (plus n est grand, plus la puissance augmente), la **taille d'effet** (plus l'effet est important, plus il est facile à détecter), le **niveau de signification (α)** (un α plus élevé augmente la puissance mais aussi le risque d'erreur), et la **variabilité des données** (une plus grande variabilité réduit la puissance).

La puissance est calculée comme : <MathInline>{"1 - \\beta"}</MathInline>
</MdxCard>

## Exemple Pratique avec Python

<MdxCard>
<CodeBlock language="python">
{`
import numpy as np
from scipy import stats
import matplotlib.pyplot as plt

# Génération de données

np.random.seed(42)
groupe1 = np.random.normal(100, 15, 30) # Moyenne=100, Écart-type=15, n=30
groupe2 = np.random.normal(110, 15, 30) # Moyenne=110, Écart-type=15, n=30

# Test de normalité

_, p_norm1 = stats.shapiro(groupe1)
_, p_norm2 = stats.shapiro(groupe2)

# Test d'homogénéité des variances

\_, p_var = stats.levene(groupe1, groupe2)

# Test t de Student

t_stat, p_value = stats.ttest_ind(groupe1, groupe2)

# Affichage des résultats

print(f"Test de normalité groupe 1: p = {p_norm1:.3f}")
print(f"Test de normalité groupe 2: p = {p_norm2:.3f}")
print(f"Test d'homogénéité des variances: p = {p_var:.3f}")
print(f"Test t de Student: t = {t_stat:.3f}, p = {p_value:.3f}")

# Visualisation

plt.figure(figsize=(10, 6))
plt.boxplot([groupe1, groupe2], labels=['Groupe 1', 'Groupe 2'])
plt.title('Comparaison des deux groupes')
plt.ylabel('Valeurs')
plt.show()
`}

</CodeBlock>
</MdxCard>

## Bonnes Pratiques

<MdxCard>
**Avant le test** : vérifier les conditions d'application, calculer la taille d'échantillon nécessaire, définir les hypothèses a priori.

**Pendant l'analyse** : examiner les données aberrantes, vérifier la qualité des données, documenter les choix méthodologiques.

**Pour l'interprétation** : ne pas confondre significativité statistique et importance pratique ; considérer la taille d'effet et le contexte.

**Pour la communication** : rapporter les statistiques descriptives, inclure les intervalles de confiance, présenter les visualisations appropriées.
</MdxCard>

## Limites et Considérations

<MdxCard>
**La significativité n'est pas tout** — une p-valeur significative ne garantit pas l'importance pratique ; la taille d'effet est souvent plus informative.

**Tests multiples** — le risque d'erreur augmente avec le nombre de tests ; corrections nécessaires (Bonferroni, FDR, etc.).

**Taille d'échantillon** — un grand n peut rendre tout significatif ; un petit n peut masquer des effets importants.

**Hypothèses sous-jacentes** — les violations peuvent invalider les résultats ; vérifier les conditions reste essentiel.
</MdxCard>
