# Métriques

<MdxCard>
  **Inventaire condensé** des métriques d'évaluation en ML supervisé. Les métriques de **performance**
  sur test sont en général **agnostiques au modèle** ; seuls les **diagnostics** (OOB, importances…)
  varient selon la famille. Protocole : train / validation / test,{' '}
  <a href="/knowledge/machine-learning/general-concepts/cross-validation">CV stratifiée</a> si
  besoin, baseline, incertitude (bootstrap ou CV), test hold-out une fois.
</MdxCard>
