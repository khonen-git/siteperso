# Metrics

<MdxCard>
  **Condensed inventory** of supervised ML evaluation metrics. **Test performance** metrics are
  usually **model-agnostic**; **diagnostics** (OOB, importances…) depend on the family. Protocol:
  train / validation / test,{' '}
  <a href="/knowledge/machine-learning/general-concepts/cross-validation">stratified CV</a> when
  needed, baseline, uncertainty (bootstrap or CV), hold-out test once.
</MdxCard>
