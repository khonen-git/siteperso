**In brief.** Before rich models, you need a stable label <MathInline>{"y"}</MathInline>. Tr8dr amplitude-based (15 bps / Tinactive 60) on EURUSD TIMB: **48.6%** signed occupancy, peak <MathInline>{"D(h)"}</MathInline> **+0.549** at H=32. ## Why I ran this study

Everything downstream (process gates, HMM, events) rests on a frozen directional segment **y**. If the label is coding noise or not economically separable, the rest is decoration.

Pipeline: L0 census → <MathInline>{"D(h)"}</MathInline> validity → univariate T2/T5 screening → C4 stack → OOS 2024 lock.

## Definition (summary)

Up / neutral / down segments via min amplitude + inactivity timeout:

<MathBlock>{"D(h) = P(r_{t\\to t+h}>0 \\mid y=\\mathrm{up}) - P(r_{t\\to t+h}>0 \\mid y=\\mathrm{down})"}</MathBlock>

| L0 metric | Value |
|-----------|------:|

| Segments / day | ~5.2 |
| Duration p50 / p90 | 83 / 206 bars |

## Key results
