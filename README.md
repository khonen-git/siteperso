# siteperso

Site personnel Next.js 15 — portfolio, knowledge base, blog recherche.

## Commandes

```bash
npm run dev           # serveur de développement
npm run validate      # lint + typecheck + jest + build
npm run test:e2e      # build + smoke Playwright (29 tests)
npm run test:e2e:dev  # smoke contre next dev déjà lancé
```
